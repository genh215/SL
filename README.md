HTML・JavaScriptの勉強用に子どもが遊べそうなものを作成しました。利用は個人の趣味の範囲に限ります。

- 画面をタップ・なぞる：目が追従する。
- 煙突をタップ：1秒間煙が出る。
- 車輪をタップ：走行開始／停止。
- 雲をタップ：車体色が青→黄緑→赤→青と切り替わる。

A project made for children as an exercise in learning HTML and JavaScript. For personal hobby use only.

- Tap or drag on the screen: the eyes follow.
- Tap the chimney: smoke appears for one second.
- Tap a wheel: start or stop running.
- Tap a cloud: cycle the body color through blue, lime green, red, and back to blue.
